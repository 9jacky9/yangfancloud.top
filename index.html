Q1: 扬帆云如何保障物理层面的严格零日志（Zero-Log）？

扬帆云生产环境核心节点全部采用纯 RAM 内存无盘系统部署，不挂载任何物理硬盘写入空间。所有网络连接数据在内存中以纳秒级流经，不记录用户的历史网络目标、不记录 DNS 访问请求，服务器在断电或重启时内存数据彻底归零，无可提取日志。

Q2: 为什么扬帆云在晚高峰依然能跑满千兆带宽？

我们斥重资采购了专属企业级 IEPL/IPLC 跨境海缆内网通道，完全绕开拥挤的国际公共互联网交换中心（IXP）。入口在国内专属 BGP 节点，出口直通香港、东京、新加坡和硅谷机房，物理级专线隔离确保高峰期不卡顿、零降速。

Q3: 支持哪些操作系统与代理客户端？

原生兼容全生态客户端，包括 iOS（Shadowrocket / Surge / Loon）、macOS / Windows（Clash Verge / v2rayN / Sing-box）、Android（Clash Meta / v2rayNG）以及各类开源软路由（OpenWrt / iStoreOS）。平台后台提供一键订阅生成与托管更新功能。
